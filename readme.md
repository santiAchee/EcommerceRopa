🛍️ Mundo Ropa - Tienda Online

¡Bienvenido al repositorio oficial de Mundo Ropa! 👋

🌟 ¿Qué es Mundo Ropa?

Mundo Ropa es una plataforma web de e-commerce moderna, rápida y súper fácil de usar, diseñada para ofrecer la mejor experiencia de compra de indumentaria online. Nuestro objetivo es conectar a los usuarios con las últimas tendencias de la moda a través de una interfaz limpia, atractiva y sin complicaciones.

Aquí los clientes pueden explorar nuestro catálogo completo, buscar sus prendas favoritas, seleccionar talles y gestionar su carrito de compras de forma totalmente intuitiva, todo en un solo lugar.

👥 Quiénes Somos

Somos un equipo apasionado por el desarrollo web y el diseño de experiencias digitales. Creemos firmemente que comprar ropa por internet no debería ser un dolor de cabeza, sino un proceso fluido y disfrutable.

Por eso, unimos nuestras ideas y habilidades para crear esta tienda virtual. Nos enfocamos en construir un producto que no solo se vea increíble, sino que funcione a la perfección y se adapte al ritmo de los usuarios de hoy. 🚀

🛠️ Stack Tecnológico

Para darle vida a este proyecto, elegimos herramientas sólidas y ágiles:

HTML5 🧱 - Para la estructura y semántica del sitio.

CSS3 🎨 - Para los estilos, diseño responsivo y animaciones fluidas.

JavaScript (Vanilla) ⚡ - Para toda la interactividad, la lógica del carrito y la conexión con la base de datos.

Airtable ☁️ - Utilizado como nuestro backend y base de datos en la nube para gestionar el catálogo de productos en tiempo real.

✨ Funcionalidades Principales

Nuestra tienda está equipada con todo lo necesario para garantizar una experiencia de compra completa:

🔍 Buscador Inteligente: Encuentra artículos rápidamente mediante palabras clave en tiempo real.

🏷️ Filtrado de Catálogo: Navega fácilmente entre distintas categorías de ropa (camperas, remeras, etc.).

🛒 Carrito de Compras Dinámico: Agrega productos, elige talles, modifica cantidades o elimina artículos de tu bolsa sin recargar la página en ningún momento.

📱 Diseño 100% Responsive: La tienda se adapta de forma impecable a cualquier dispositivo, ya sea que entres desde tu celular, una tablet o la compu de escritorio.

💳 Checkout Integrado: Un formulario de finalización de compra que valida tus datos al instante para asegurar que la transacción sea correcta.

🔔 Notificaciones Amigables: Alertas visuales flotantes que te avisan al instante cuando un producto se suma a tu carrito.
